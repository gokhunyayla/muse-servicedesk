# Directory and folder permissions

Symptom: "I can't open the shared folder", "access denied", "I need access to the X group".

1. A permission change needs manager approval: request_manager_approval (the ticket waits for it).
2. When approved: add_to_group with the group that grants the access.
3. Ask the employee to sign out and back in (group membership is read at sign-in); get confirmation.
4. Temporary access: schedule_followup on the end date and remove_from_groups then.
